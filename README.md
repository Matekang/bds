## 🚀 Khởi Chạy Nhanh

1. **Cài đặt dependencies:**
   ```bash
   npm install
   ```

2. **Chạy server phát triển (Development):**
   ```bash
   npm run dev
   ```
   Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt.

3. **Biên dịch cho sản xuất (Production):**
   ```bash
   npm run build
   npm run start
   ```
